# Xteink X4 轉檔指南 (XTC+ 高清封面版)

此工具已針對 XTEINK X4 最佳化，支援自動 CSS 客製化清理、彩色高清封面嵌入，以及直書/橫書自動排版。

## 1. 快速轉檔指令

現在只需一個指令即可完成單檔或整個目錄的轉檔。程式會**自動進行 EPUB 優化**（移除干擾字級、清理 CSS）並產出 XTC 檔案。

### 轉單一檔案
```bash
node index.js convert "books/書名.epub" -c 設定檔.json
```

### 批次轉整個目錄
```bash
node index.js convert "books/" -c 設定檔.json
```

## 2. 精選設定檔 (Settings Profiles)

請根據您的閱讀偏好選擇以下精心設計的設定檔：

| 設定檔名稱 | 說明 | 適用字體 |
| :--- | :--- | :--- |
| `settings_明體直書.json` | **直排首選**：90度旋轉，適合長篇小說 | 明蘭體 |
| `settings_黑體直書.json` | **直排清晰**：90度旋轉，字體較濃厚 | 台北黑體 |
| `settings_中文橫書.json` | **橫排標準**：適合技術書籍或習慣橫讀 | 台北黑體 (預設) |

> [!TIP]
> 使用直排設定檔時，請將 X4 裝置**橫向拿持**（HOME 鍵在右側），即可享受最完美的直書效果。

## 3. 功能特色

- **自動化優化**：轉檔時會自動移除原書中導致渲染崩潰或影響字級的 CSS（例如 `box-shadow`、`text-shadow`）。
- **高品質封面**：偵測 EPUB 中的封面並以彩色 JPG 嵌入，確保 X4 主畫面的縮圖清晰美觀。
- **進程隔離**：批次轉檔時採取「一書一進程」模式，處理數千頁的大書也能保持 100% 穩定，不會崩潰。
